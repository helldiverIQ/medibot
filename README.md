# 🩺 MediBot Secure

روبوت محادثة طبي باللغة العربية مع تسجيل دخول آمن برمز تحقق (OTP) يصل على البريد، ولوحة مراقبة أمنية للأدمن.
مشروع تخرج — مكتوب بلغة Python فقط ولا يحتاج تثبيت أي مكتبة (Python 3.8 أو أحدث).

> ⚠️ يقدّم MediBot معلومات صحية عامة ولا يغني عن الطبيب.

## المميزات
- تسجيل دخول بالتحقق الثنائي OTP عبر البريد (مع قفل الحساب بعد محاولات خاطئة وحد للطلبات)
- محرك طبي مدمج: 41 مرض و131 عرض، يفهم اللهجات والنفي ويسأل أسئلة متابعة
- ذكاء اصطناعي أونلاين (Groq أو Pollinations) مع رجوع تلقائي للمحرك المدمج
- كشف الحالات الطارئة وعبارات إيذاء النفس
- لوحة أدمن: سجلات الوصول، التنبيهات، الجلسات، المحادثات
- اختبارات وظيفية وأمنية: `python app.py test`

## التشغيل على جهازك
1. انسخ `.env.example` باسم `.env` وضع فيه مفاتيحك (اختياري)
2. شغّل `run.bat` (ويندوز) أو `python app.py`
3. يفتح المتصفح تلقائياً على `http://127.0.0.1:5000`

إذا لم تضبط البريد، يُطبع رمز التحقق في نافذة التشغيل (وضع التجربة).

## الإعدادات (متغيرات البيئة أو ملف `.env`)
| المتغير | الوصف |
|---|---|
| `GROQ_API_KEY` | مفتاح Groq للذكاء الاصطناعي (من console.groq.com/keys) |
| `ADMINS` | حسابات الأدمن بالصيغة `user1:pass1,user2:pass2` |
| `SMTP_EMAIL` | البريد المُرسِل لرموز التحقق |
| `SMTP_PASSWORD` | كلمة مرور التطبيقات (Gmail App Password) — للتشغيل المحلي |
| `BREVO_API_KEY` | بديل SMTP يعمل عبر HTTPS (مطلوب على الاستضافات التي تحجب منافذ البريد) |

## النشر على الإنترنت (Render)
1. ارفع المستودع على GitHub
2. في [render.com](https://render.com): New → Blueprint → اختر المستودع (يقرأ `render.yaml` تلقائياً)
3. ضع قيم `GROQ_API_KEY` و`ADMINS` و`SMTP_EMAIL` و`BREVO_API_KEY` في صفحة Environment

ملاحظات:
- الخطة المجانية في Render تحجب منافذ SMTP، لذلك استخدم Brevo (خطة مجانية) لإرسال الرموز، و`SMTP_EMAIL` يجب أن يكون مُرسِلاً موثّقاً في Brevo
- قاعدة البيانات SQLite تُمسح عند إعادة تشغيل الخدمة أو النشر في الخطة المجانية
- الخدمة المجانية تنام بعد فترة خمول، وأول طلب بعدها يأخذ وقتاً أطول

## الملفات
- `app.py` — الخادم والواجهة ومحرك البوت والاختبارات
- `medical_data.json` — قاعدة المعرفة الطبية (مصدر مصفوفة الأمراض والأعراض: github.com/itachi9604/healthcare-chatbot)
- `run.bat` — تشغيل سريع على ويندوز
- `render.yaml` — إعداد النشر على Render
